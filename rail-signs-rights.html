四、班次取消 / 大延誤：你嘅權利

🇦🇹 ÖBB（奧地利國鐵）官方條款

如果班次取消，或者遲 超過 60 分鐘，你可以揀：

  • 唔搭，全額退票（出發前放棄行程）
  • 免費搭下一班，可以改路線、改時間
  • 中途放棄，退未搭嗰段車費
  • 行程已無意義：用其他班次即刻返起點，全額退票
  • 100 分鐘內冇人話你知點轉車 → 可以自己買其他公共交通（火車或巴士）嘅票繼續行程，合理費用可索償

🇩🇪 DB（德鐵）官方條款

符合以下情況 → Zugbindung aufgehoben（班次綁定解除）：

  • 班次取消、停站取消
  • 預計到達遲 ≥20 分鐘（國內） / ≥60 分鐘（國際）
  • 趕唔到接駁班次、班次提早開

解除之後：可以搭任何 DB 長途車（ICE / IC / EC）同區域車，可以改路線，亦可以揀較後班次（同日、翌日、甚至 3 星期後；原定出發日起一年內有效）；長途仲可以搭同日較早班次。

💰 賠償（歐盟 1371/2007 規則，DB 同 ÖBB 一樣）
遲 60–119 分鐘 → 退 25% 票價 ｜ 遲 ≥120 分鐘 → 退 50% 票價
班次取消而你唔搭 → 可以要求全額退款（同賠償二擇其一，唔可以兩樣都要）。

🧾 索償 4 步

  • 1. 攞證明：喺車站 Service Point / Reisezentrum 或車上職員攞 Bestätigung（延誤／取消證明）
  • 2. 留單據：車票、座位預訂（取消行程嘅座位預訂可以免費退）、額外交通收據
  • 3. 交表：DB 用 bahn.de 嘅 Fahrgastrechte 表格；ÖBB 用 oebb.at 嘅 Fahrgastrechte / 客服
  • 4. 等回覆：保留副本；跨國票通常由賣票嗰間公司處理
